# EXE REACTOR · asset host

Hosted files for the **EXE REACTOR** StreamElements widget by form&soul.exe
(GitHub Pages: https://feder0707.github.io/exe-reactor-assets/).

- `engine/` — scene engine (JS + CSS) loaded by the widget
- `assets/` — images (WebP) and sounds (MP3)
- `index.html` — live preview of the scene
- `CREDITS.md` — audio credits and licenses

Do not rename this repository or move files: purchased widgets load them from these URLs.
